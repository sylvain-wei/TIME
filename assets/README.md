# README visual assets

`hero.png` is original AI-generated artwork created for TIME with OpenAI ImageGen: a monochrome, humanist view of a railway concourse, moving travelers, and an analog station clock. It is a photographic illustration, not documentary photography of an identified location. The native generated file is 2167 × 726 pixels (approximately 3:1); it has not been upscaled.

`hero.svg` is the README display asset. Its canvas is exactly **3840 × 1101**, matching the ReVuE README header ratio. It embeds the original PNG unchanged, fits it proportionally to the canvas width, and clips only the bottom through a top-aligned SVG viewport. There is no geometric stretching; the full clock and title remain in view. The SVG is a layout wrapper around raster artwork, not a vector photograph or a new native 4K image.

The TIME title and paper subtitle are part of the generated artwork. The banner's centered white typography takes its layout direction from the ReVuE README, while the imagery and grayscale treatment were created for TIME.

The dataset overview, construction pipeline, three radar plots, institution marks, and existing TIME logo are retained from the repository without pixel changes. The README displays the three radar plots together and links each to its original full-resolution file.
